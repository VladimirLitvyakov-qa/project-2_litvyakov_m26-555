# Primitive DB

Консольная база данных на JSON-файлах с CRUD-операциями.

## Установка

```
uv sync
uv run database
```

## Демонстрация
[Демонстрация в asciinema](https://asciinema.org/a/nNFDaH4arKk8BJtw)

## Управление таблицами

### Запуск:

```
database
```

### Команды:

| Команды                                                                      | Что делает                   |
|------------------------------------------------------------------------------|------------------------------|
| `create_table <имя> <столбец:тип> ...`                                       | создать таблицу              |
| `list_tables`                                                                | показать список таблиц       |
| `drop_table <имя>`                                                           | удалить таблицу              |
| `help`                                                                       | справка                      |
| `exit`                                                                       | выход                        |

### Демонстрация:

[Демонстрация в asciinema](https://asciinema.org/a/AOqFDUsGQ7ysPznO)

Типы столбцов: `int`, `str`, `bool`. 

Столбец `ID:int` добавляется автоматически.

### Пример:

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.
>>>Введите команду: exit
```

## CRUD-операции:

### Команды:

| Команды                                                                      | Что делает                   |
|------------------------------------------------------------------------------|------------------------------|
| `insert into <имя> values (<значение1>, ...)`                                | создать запись               |
| `select from <имя> where <столбец> = <значение>`                             | прочитать запись по условию  |
| `select from <имя>`                                                          | прочитать все записи         |
| `update <имя> set <столбец> = <новое значение> where <столбец> = <значение>` | обновить запись              |
| `delete from <имя> where <столбец> = <значение>`                             | удалить запись               |
| `info <имя>`                                                                 | вывести информацию о таблице |

### Демонстрация:

[Демонстрация в asciinema](https://asciinema.org/a/KwHJTV4uUmLGoIQ7)

Строковые значения пишутся в кавычках: `"Sergei"`. Числа и `true`/`false` — без кавычек.

### Пример:

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  29 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок:

Декоратор `handle_db_errors` ловит следующие типы ошибок:

| Ошибка              | Когда возникает       | Что видит пользователь                                                     |
|---------------------|-----------------------|----------------------------------------------------------------------------|
| `FileNotFoundError` | файл не найден        | `Ошибка: Файл данных не найден. Возможно, база данных не инициализирована` |
| `KeyError`          | таблица не существует | `Ошибка: Таблица или столбец ... не найден.`                               |
| `ValueError`        | ошибка валидации      | `Ошибка валидации: ...`                                                    |
| `Exception`         | технические ошибки    | `Произошла непредвиденная ошибка: ...`                                     |

### Демонстрация:
[Демонстрация в asciinema](https://asciinema.org/a/lUeCgxbC3BCkzG44)

### Пример:
```
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int
>>>Введите команду: create_table products title:float
Ошибка валидации: некорректное значение: title:float. Попробуйте снова.
>>>Введите команду: insert into orders values ("Book", 100)
Ошибка: Таблица или столбец 'orders' не найден.
Функция insert выполнилась за 0.000 секунд.
>>>Введите команду: exit
```

## Подтверждение действий

Команды `drop_table` и `delete` перед выполнением запрашивают подтверждение:

- `y` - подтвердить
- `n` или любой другой ввод - отменить

### Демонстрация:
[Демонстрация в asciinema](https://asciinema.org/a/mJngiaF6c38gxe3k)

### Пример:
```
>>>Введите команду: insert into users values ("Ivan", 31)
Функция insert выполнилась за 0.000 секунд.
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: delete from users where name = "Ivan"
Функция select выполнилась за 0.000 секунд.
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена
>>>Введите команду: delete from users where name = "Ivan"
Функция select выполнилась за 0.000 секунд.
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
>>>Введите команду: exit
```
